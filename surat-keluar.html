Buat Surat Keluar
Permintaan surat keluar diajukan Anggota Dewan melalui aplikasi mobile dan masuk ke seluruh Admin Sekretariat (SETWAN). Satu admin mengklaim permintaan (In Progress), mengunggah file surat, lalu submit — surat langsung berstatus Selesai tanpa perlu persetujuan balik dari Anggota. Admin juga dapat membuat surat keluar langsung dari web untuk surat yang sudah jadi di luar sistem — statusnya langsung tercatat Selesai.
